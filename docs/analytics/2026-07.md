# Analytics snapshot — July 2026

Captured 2026-07-27. **Vercel Hobby only retains 30 days**, so these numbers are
gone from the dashboard by late August — this file is the only copy. Repeat on
the 1st of each month.

## Caveats that matter when reading this

- **GA4 sees roughly 12% of real traffic.** Same window: Vercel 150 pageviews vs
  GA4 18. Confirmed cause — `googletagmanager.com` returns 503 in browsers with
  a tracker blocker (verified live; `curl` from the same machine returns 200).
  Treat Vercel as the source of truth for volume, GA4 for behaviour only.
- **GA4 consent rate was 0%.** Google's own tag diagnostics: "100% of your
  consent signals are marked as denied". Every hit was cookieless, so user and
  session counts are inflated and attribution is degraded.
- **`case_study_view` was being dropped on direct page loads** until the fix
  shipped on 2026-07-27 (commit `a562fea`). Its counts below are an undercount,
  and the view/read ratio is not meaningful.
- Vercel figures are production only, hostname `lucasmujica.dev` (100% of
  traffic — no vercel.app or preview contamination).

## Google Search Console — 3 months

**8 clicks · 114 impressions · 7% CTR · average position 6.8**
**18 pages indexed · 7 not indexed.**

The 7 not indexed are not a problem: 3 redirects, 1 discovered-not-yet-crawled,
and 3 "crawled – currently not indexed" which are two `opengraph-image` routes
and a `.woff2` font file. **Every real content page is indexed.**

| Query | Clicks | Impressions | Avg position |
|---|---|---|---|
| lucas mujica | 5 | 30 | 4.3 |
| nextfense | 0 | 2 | 7.0 |
| componentizado | 0 | 1 | 10.0 |
| true north jerseys | 0 | 1 | 12.0 |

**Four queries total, and three of them are Lucas's own name or a client's.**
100% of search visibility is brand/navigational — nobody finds the site
searching for the service. `componentizado` is the single accidental non-brand
impression. And the brand query itself only averages position 4.3.

This is the clearest statement of the problem: indexing is healthy, ranking is
fine where the site appears, but there is no content targeting any query a
buyer would actually type.
